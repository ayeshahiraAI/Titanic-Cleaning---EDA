# Titanic-Cleaning---EDA
 Collected a raw dataset from an external source and cleaned it by removing duplicates, handling missing values using Python and Pandas.Performed exploratory data analysis by computing summary statistics, identifying outliers and correlations, and visualizing data using Matplotlib and Seaborn to extract meaningful insights.

# Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Overview
Collect and prepare raw data for analysis and perform EDA on the dataset I cleanend.
Calculate basic statistics such as mean, median, maximum, and minimum
values to better understand the dataset. Also identify outliers,
correlations, and overall patterns. Using Matplotlib and Seaborn.
Create basic visualizations like bar charts, histograms, and line graphs.


## Key Insights
- Performed exploratory data analysis on Titanic dataset
- Identified survival patterns using statistical analysis and visualization
- Females had higher survival rates than males
